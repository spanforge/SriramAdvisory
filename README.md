# Sriram Advisory

A minimal one-page website introducing Think Sriram, AInternals, and Adoptrivo.

The website source and deployment instructions are in [sriram-advisory](sriram-advisory/README.md).

From that directory, run `npm run dev` to preview or `npm run build` to generate the static `dist/` directory. No dependency installation is required. In Windows PowerShell with restricted script execution, use `npm.cmd` in place of `npm`.
